# 🪖 Colonel Blotto

A multiplayer game theory strategy game built for MLH Fellowship.

## What is Colonel Blotto?

You have **100 troops** to distribute across **5 battlefields**. So does every other player. Each battlefield is won by whoever sends the most troops there. Win the most battlefields, win the round. You face every other player 1v1 — most wins across all matchups = tournament leader.

## Tech Stack
- **Frontend**: React + Vite
- **Backend**: Node.js + Express + Socket.io
